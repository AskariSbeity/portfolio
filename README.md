## Featured Projects

### ChefMate — Full-Stack Recipe Platform

A full-stack recipe and cooking platform built around ingredient-based recipe discovery.

Users can enter ingredients they already have and discover recipes they can prepare while also accessing tools for managing their cooking experience.

**Key Features**
- Ingredient-based recipe matching
- Recipe search and filtering
- Pantry management
- Meal planning
- Favorites
- User profiles
- JWT authentication
- AI cooking assistant
- Responsive interface

**Technologies**

`React` `TypeScript` `Node.js` `Express.js` `MySQL` `JWT` `Tailwind CSS` `Framer Motion`

---

### ChefMate Mobile

A dedicated mobile version of ChefMate designed and developed using Flutter and Dart.

The application translates the ChefMate experience into a touch-first mobile interface while maintaining the core recipe discovery and kitchen management functionality.

**Key Features**
- Mobile recipe discovery
- Ingredient-based recipe matching
- Pantry management
- Meal planner
- Favorites and profiles
- REST API integration
- Mobile-focused navigation
- Responsive Flutter interface

**Technologies**

`Flutter` `Dart` `REST API` `JSON` `Material UI`

## Design Philosophy

The portfolio follows a minimalist editorial approach built primarily around black, white, and grayscale.

Rather than relying heavily on color, the interface uses typography, spacing, contrast, borders, motion, and structured layouts to create visual hierarchy.

Project cards use custom visual compositions while detailed screenshots and technical information are presented through interactive project modals.

---

## Responsive Design

The portfolio is designed to work across:

- Desktop computers
- Laptops
- Tablets
- Mobile devices

Layouts, typography, navigation, project cards, project previews, and modal components adapt to smaller screen sizes.
