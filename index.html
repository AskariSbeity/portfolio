    07 — How I Build

    From idea to shipped product.

    01

    Discover

    Ask questions, study the problem, and understand who the product is really for before touching a single line of code.

    02

    Plan

    Map the structure — flows, data, and layout — so every build decision has a clear reason behind it.

    03

    Build

    Write clean, modular code and turn the plan into a real, working interface — piece by piece.

    04

    Test

    Break it on purpose. Check every state, screen size, and edge case before it ever reaches a user.

    05

    Refine

    Polish the details that make it feel finished — performance, motion, and the small things people notice.
